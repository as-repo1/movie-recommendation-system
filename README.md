# Movie Recommendation System

A **content-based** movie recommendation engine built with Python and Streamlit.
Given a movie you like, it finds the most similar movies by analysing their
genres, keywords, cast, crew, and overview using **CountVectorizer** + **Cosine Similarity**.

## How It Works

### Preprocessing pipeline (`src/preprocessing.py`)

| Step | Action |
|------|--------|
| **Load** | Read `tmdb_5000_movies.csv` + `tmdb_5000_credits.csv`, merge on `title` |
| **Filter** | Keep: `movie_id`, `title`, `overview`, `genres`, `keywords`, `cast`, `crew` |
| **Clean** | Drop nulls and duplicates |
| **Extract** | Parse JSON strings → Python lists; limit cast to top 3; director only |
| **Collapse** | Remove spaces from multi-word names (e.g. `Sam Worthington` → `SamWorthington`) |
| **Tags** | Combine all fields into a single lowercase `tags` string per movie |
| **Stem** | Apply Porter stemmer so "love / loved / loving" all map to the same root |

### Vectorisation & similarity (`scripts/build_model.py`)

- `CountVectorizer(max_features=5000, stop_words='english')` → sparse feature matrix
- `cosine_similarity` → NxN similarity matrix
- Both the slim DataFrame and the matrix are serialised to `data/processed/`

### Recommendation (`src/recommender.py`)

Given a movie title, its row in the similarity matrix is retrieved, sorted
descending, and the top-N similar movies are returned as a list of dicts.

## Setup & Installation

### 1. Clone and install

```bash
git clone <repo-url>
cd movie-recommendation-system
pip install -r requirements.txt
```

### 2. Build the model

The build script auto-unzips the archives and runs the full pipeline:

```bash
python scripts/build_model.py
```

Options:

```
--raw-dir       Path to TMDB CSV files (default: data/raw)
--output-dir    Where to write .pkl files (default: data/processed)
--max-features  CountVectorizer vocabulary size (default: 5000)
```

### 3. Run the app

```bash
streamlit run app.py
```

Open `http://localhost:8501`.

## Running with Docker Compose (Recommended)

To run the complete **RecLens** stack (FastAPI Backend + React Frontend + PostgreSQL Database + Nginx Proxy) containerized:

### 1. Build and Start the Services
First, ensure that the model datasets have been built (see *Build the model* section). Then run:

```bash
docker compose up -d
```

This command will:
- Spin up a PostgreSQL database container.
- Build the FastAPI backend container (installing systems requirements like `gcc`, `pyarrow`, and `lightfm`).
- Build the React production bundle and serve it via static `serve` on port 5173.
- Start an Nginx reverse proxy on port 80 routing `/` to the frontend and `/api` to the backend.

### 2. Access Points
- **Web Application UI**: [http://localhost/](http://localhost/)
- **FastAPI Interactive Documentation**: [http://localhost/docs](http://localhost/docs)
- **Backend API Health Check**: [http://localhost/health](http://localhost/health)

### 3. Development Mode (Hot-Reloading)
To run the containers with hot-reloading for code changes (Vite HMR and FastAPI Uvicorn reload):

```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up
```

## Poster Images

Posters are fetched in priority order:

| Tier | Source | Requirement |
|------|--------|-------------|
| 1 | **TMDB API** | Free API key (best quality) |
| 2 | **OMDb demo** | No key needed (limited coverage) |
| 3 | **Placeholder** | Always available |

To use the TMDB API, either:
- Paste your key in the **⚙️ Settings** sidebar, or
- Export it as an environment variable: `export TMDB_API_KEY=your_key`

Get a free key at [themoviedb.org/settings/api](https://www.themoviedb.org/settings/api).
